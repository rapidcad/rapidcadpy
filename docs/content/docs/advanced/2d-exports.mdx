# PNG Rendering Feature

## Live technical drawing formats

The live-CAD `generate_drawing` operation accepts an `output_formats` list with
`pdf`, `idw`, `dwg`, and `dxf` as backend-neutral values. Format support is
declared by the selected drawing adapter:

| Adapter | PDF | DXF | DWG | IDW |
| --- | --- | --- | --- | --- |
| FreeCAD TechDraw | Yes | Yes | No | No |
| Autodesk Inventor | Adapter pending (RAP-87) | Adapter pending (RAP-87) | Adapter pending (RAP-87) | Adapter pending (RAP-87) |

FreeCAD writes the complete TechDraw page directly to DXF, including projected
views and annotations. It deliberately rejects DWG because native DWG output
requires an external converter such as ODA; RapidCADPy does not silently add a
lossy or unlicensed conversion step. IDW is an Inventor-native format. An
Inventor drawing adapter can implement all four formats behind the same
`DrawingBackendFactory` contract without changing callers or the MCP tool.

```python
session.generate_drawing(output_formats=["pdf", "dxf"])
```

### Automatic dimensions from semantic features

FreeCAD drawings prefer RapidCADPy's semantic `HoleFeature`, `FilletFeature`,
and `ChamferFeature` definitions. The generated Front and Top views receive
overall dimensions, grouped hole diameter/depth callouts, centre-to-centre
hole-pattern spacing, and fillet/chamfer callouts without inferring modelling
intent from the result shape. Repeated equal features use engineering
multiplicity notation such as `4X ⌀10,00 THRU` or `3X R3,00` instead of
duplicate callouts.

Imported STEP solids have no feature history. They receive overall dimensions,
but feature-specific dimensions require explicit semantic features; the backend
does not infer manufacturing intent from raw topology. The result metadata
reports `dimension_source` as `semantic_features` or `none`.

Dimension text and lines are placed in collision-checked lanes outside the
projected-view boundaries. `standard="ISO"` uses millimetres and a decimal
comma; `standard="ASME"` converts values to inches and uses a decimal point.
The result metadata includes every semantic dimension, its sheet placement,
the selected unit system, and the dimension source.

## Overview

RapidCADpy provides PNG rendering capabilities for the OCC backend with two distinct methods:

1. **`to_png()`** - Technical drawings using Hidden Line Removal (HLR)

## Quick Start

### Technical Drawing (HLR)
```python
shape.to_png("output.png", "Z")  # Top view, technical drawing
```

### 3D Rendered Image
```python
shape.to_png_rendered("output.png", "iso")  # Isometric view, shaded
```

Uses OpenCascade's Hidden Line Removal algorithm for engineering-style orthographic projections.

### Usage

```python
from rapidcadpy.integrations.occ.app import OpenCascadeApp

app = OpenCascadeApp()
wp = app.work_plane("XY")

# Create a shape
shape = wp.rect(10, 10).extrude(5)

# Render from different views
shape.to_png("output_x.png", "X")  # Right view (YZ plane)
shape.to_png("output_y.png", "Y")  # Front view (XZ plane)
shape.to_png("output_z.png", "Z")  # Top view (XY plane)
```

### Method Signature

```python
def to_png(self, file_name: str, view: str = "X") -> None:
    """
    Render the shape to a PNG file from a specified camera angle.

    Args:
        file_name: Path to save the PNG file
        view: Camera view direction - "X", "Y", or "Z" (default: "X")
             - "X": Looking along X-axis (YZ plane view, similar to RIGHT view)
             - "Y": Looking along Y-axis (XZ plane view, similar to FRONT view)
             - "Z": Looking along Z-axis (XY plane view, similar to TOP view)

    Raises:
        ValueError: If view is not one of "X", "Y", or "Z"
    """
```


### Backends

The method tries backends in this order (unless specified):

1. **pyvista** (Recommended - fast, simple, and lightweight)
   ```bash
   pip install pyvista
   ```

2. **vedo** (Feature-rich, scientific viz)
   ```bash
   pip install vedo
   ```

**Backend Selection:**
- `backend="auto"` - Try pyvista → vedo (default)
- `backend="pyvista"` - Use pyvista only (fastest)
- `backend="vedo"` - Use vedo only

### View Options

| View Name | Aliases | Description |
|-----------|---------|-------------|
| "iso" | "isometric" | 3D isometric view (45° angles) |
| "front" | "Y" | Front view (looking along Y-axis) |
| "top" | "Z" | Top view (looking down Z-axis) |
| "right" | "X" | Right view (looking along X-axis) |
