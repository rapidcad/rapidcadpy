# Fluent API Examples

RapidCADpy provides a fluent API that allows you to create CAD models using an intuitive, chainable interface. This guide demonstrates various examples of creating 3D models using the fluent API.

## Inventor Backend and App Approach

RapidCADpy now supports a backend-specific `App` class for direct integration with Inventor. This enables you to manage documents and workplanes in a way that closely matches Inventor's workflow.

### Setting up an Inventor App and Workplane

```python
from rapidcadpy.integrations.inventor import InventorApp

# Initialize Inventor application
app = InventorApp()
app.new_document()

# Create a workplane on the XY plane
wp = app.work_plane("XY")
```

## Creating and Modifying Shapes

### Adding a Semantic Hole to a Live CAD Object

```python
from rapidcadpy import CadSession

session = CadSession()

# `arm_id` and `revision` come from a previously created or opened live body.
# This creates a semantic native feature; do not model a hole by extruding a
# circle and cutting it from the body.
result = session.hole(
    target_id=arm_id,
    diameter=8.0,
    center=[0.0, 45.0, 5.0],
    axis=[0.0, 0.0, 1.0],
    through=True,
    expected_revision=revision,
)

if not result["ok"]:
    raise RuntimeError(result["error"])

hole_feature_id = result["object_id"]
revision = result["document_revision"]
```

`CadSession.hole()` preserves semantic feature intent for later editing and
technical-drawing callouts. It currently supports simple through and blind
holes. Countersink and counterbore hole types are not yet supported by the
live FreeCAD executor; do not emulate them with raw FreeCAD code or boolean
cuts.

### Lofting Ordered Workplane Profiles

Create each closed profile on its own workplane, then pass the ordered
workplane IDs to `CadSession.loft()`. The FreeCAD adapter creates an editable
native `Part::Loft` with those profiles as its sections.

```python
# Each work_plane call returns an object_id. Create its profile before moving
# to the next workplane.
top = session.work_plane("XY", offset=60.0)["object_id"]
session.circle(8.0)

neck = session.work_plane("XY", offset=52.0)["object_id"]
session.circle(4.0)

result = session.loft(
    profile_workplane_ids=[top, neck],
    make_solid=True,
    ruled=False,
    expected_revision=revision,
)
loft_id = result["object_id"]
revision = result["document_revision"]
```

`profile_workplane_ids` must contain at least two distinct workplanes in loft
order. `list_objects()` can be used to inspect previously created workplane
IDs. The current public operation creates a new loft body; join and cut
operations are not exposed yet.

## Simple Shapes

### Creating a Cube

```python
app = InventorApp()
app.new_document()
wp = app.work_plane("XY")
cube = wp.move_to(-5, -5).rect(10, 10).extrude(10)
cube.export("cube.step")
```

### Creating a Cylinder

```python
app = InventorApp()
app.new_document()
wp = app.work_plane("XY")
cylinder = wp.move_to(0, 0).circle(5).extrude(20)
```

## Best Practices

- Use `InventorApp()` to manage Inventor documents and workplanes.
- Chain operations fluently for readable and concise code.
- Use named planes like `"XY"`, `"XZ"`, or `"YZ"` for standard workplanes.
